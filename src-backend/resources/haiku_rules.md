# Haiku Generation Rules

## Strict Requirements

### Syllable Structure
- **Stance 1:** Exactly 5 syllables
- **Stance 2:** Exactly 7 syllables
- **Stance 3:** Exactly 5 syllables
- **Total:** 17 syllables across all stances

### Word Integrity (CRITICAL)
- **NO word breaks across lines** - each line must contain complete words only
- **NO hyphenation** - words cannot be split with hyphens across lines
- Each line should form a **complete phrase** or **thought unit**

### Format
```
First line (5 syllables) — Second line (7 syllables) — Third line (5 syllables)
```

**IMPORTANT:** Do not number the haiku lines in the final output. Each haiku should be a single line with em dashes as separators, not separate numbered lines.

## Invalid Examples

❌ **Word bleeding across lines:**
```
Katherine Johnson — Calculated moon's trajec — tory by hand
Bitcoin miners dig — Crypto gold from math equa — tions, energy burned
Von Neumann archi — tecture still powers machines — Stored program genius
```

❌ **Wrong syllable counts:**
```
Fake news (2) — Misinformation spreads faster than truth (11) — Lies run while truth limps (5)
Botnets (2) — Hijacked computers become zombie armies (12) — Enslaved machines attack (6)
```

## Valid Examples

✅ **Complete words, correct syllables:**
```
Zero day exploits lurk (5) — In shadows of unpatched code (7) — Silent death awaits (5)
Neural pathways spark (5) — Artificial minds awake (7) — Silicon dreams bloom (5)
Python whitespace rules (5) — Indentation matters much (7) — One tab breaks it all (5)
```

## Syllable Counting Guidelines

### Technical Terms
- **TCP/IP** = "Tee-Cee-Pee-Aye-Pee" = 5 syllables
- **API** = "Ay-Pee-Eye" = 3 syllables
- **SQL** = "Es-Que-El" = 3 syllables
- **CPU** = "Cee-Pee-You" = 3 syllables
- **GPU** = "Gee-Pee-You" = 3 syllables

### Common Words
- **JavaScript** = "Ja-va-Script" = 3 syllables
- **Python** = "Py-thon" = 2 syllables
- **Algorithm** = "Al-go-rithm" = 3 syllables
- **Database** = "Da-ta-base" = 3 syllables
- **Network** = "Net-work" = 2 syllables

### Names
- **Ada Lovelace** = "A-da Love-lace" = 4 syllables
- **Alan Turing** = "A-lan Tur-ing" = 4 syllables
- **Steve Jobs** = "Steve Jobs" = 2 syllables
- **Bill Gates** = "Bill Gates" = 2 syllables

## Validation Process

Before accepting any haiku:

1. **Count syllables** in each line (5-7-5)
2. **Check word integrity** - no words split across lines
3. **Verify meaning** - each line should make sense
4. **Confirm format** - proper em dashes as separators

## Themes

- Computing/programming concepts
- Cybersecurity and digital threats
- AI/Machine learning
- Quantum computing
- Programming languages and their quirks
- Tech industry history and legends
- Software engineering practices
- Digital culture and internet phenomena

## Style

- **Tone:** Dark, edgy, sometimes humorous
- **Perspective:** From a programmer/hacker viewpoint
- **Language:** Technical but poetic
- **Imagery:** Digital, computational, sometimes dystopian
